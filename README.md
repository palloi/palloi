# Palloi Hofmann

Site pessoal de [Palloi Hofmann](https://palloi.com.br): tech manager, tech lead e desenvolvedor.

Página estática em HTML, Tailwind CSS e JavaScript, com conteúdo em português e inglês.

## Local

Abra `index.html` no navegador ou sirva a pasta:

```bash
python3 -m http.server 4173
```

Depois acesse `http://localhost:4173`.

## Publicação

O arquivo `CNAME` aponta para `palloi.com.br`. No GitHub Pages, publique a branch principal na raiz do repositório.
